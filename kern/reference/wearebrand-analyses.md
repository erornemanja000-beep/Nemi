Meltemi "Modern white villa with black steel glazing and a travertine volume, infinity pool and white deck on a canal under palms, villas across the water, late afternoon." Aurea "Two-storey glass-and-stone villa at blue hour, warm interior, floating oak staircase, pool with blue lights."
2. Empty plots by editing/inpainting the finished frame (same seed + camera): "Remove the house, pool and garden; same camera, lens, horizon and light; untouched wild plot." Meltemi dusk still: "same image at blue hour, interiors lit, car on the drive."
3. Build clips (start empty → end finished, 6–8 s, static camera): "Construction time-lapse: ground graded, setting-out lines, concrete slab, rebar, timber frame, walls rise left to right, upper floor, roof, pool fills, landscaping grows; locked tripod, no camera move, consistent lighting." Several takes, keep the clearest build order.
4. Aurea: 3 chained clips (each starts on previous last frame): exterior through open door → interior; interior → terrace; terrace → pool, tilt into dark water.
5. Export 24–30 fps, ~120–180 frames/villa; desktop 1920×1080 WebP q75, mobile 1080×1350 crop or 720p; preload villa 1, lazy-load rest.
6. Front end: pinned sticky 100vh canvas (cover), ~400vh per villa, ~600vh Aurea; one master ScrollTrigger scrub .5 → global frame index; crossfades draw both frames with globalAlpha over ~3% scroll; copy/status at 25/50/75% as .15 s crossfades; title out ~97%, next in ~3%; Lenis.
7. Manifesto: split chars; on enter "·" → scramble 4–6 ticks → resolve, stagger ~.1 s/line; echo = 2 copies (::before/::after or text-shadow) ±.3em vertical, cyan/blue, opacity .4, blur(1px), tween to 0; drive offset from ScrollTrigger.getVelocity().
8. Content: logo + "0X / 04" counter; eyebrow status per phase; SITE / PROGRAM / FOOTPRINT rows; manifesto + 3 columns; "Four villas in the …" + INDEX OF WORKS.

## Premium / pitfalls
Hero already = first villa's empty plot (no visible section switch); locked camera so land becomes building; copy narrates each phase live; day → night across portfolio; final dolly takes you inside and out to the terrace; holds let each build land; restrained type.
Pitfalls: camera drift between keyframes (derive empty from finished), ghosting at clip seams (f743–756), payload 700+ frames (WebP, staged preload, mobile sequences), text contrast (soft gradient bottom-left), wheel-mouse jitter (Lenis/lerp), prefers-reduced-motion → static keyframes + fades.
